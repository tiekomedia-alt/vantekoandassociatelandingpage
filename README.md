# David Vanteko — Executive Landing Page

Personal executive landing page for **David Vanteko**: Attorney, Compliance Officer, Digital Strategist, and Global Virtual Manager.

## 🎨 Color Palette

| Color | Hex Code | Purpose |
|---|---|---|
| **Navy** | `#111C2E` | Primary background & brand base |
| **Gold** | `#C6A66B` | Primary accents, buttons, & monogram |
| **Ivory** | `#F6F2E9` | Body text & card elements |
| **White** | `#FFFFFF` | Headings & crisp accents |

---

## ⚡ Features

- **Personal Brand Focus**: Highlights your professional photo (`assets/images/david-vanteko.jpg`).
- **Core Pillars**:
  1. Attorney & Legal Counsel
  2. Compliance Officer
  3. Digital Strategist
  4. Global Virtual Manager
- **Calendly Integration**: Direct consultation booking via `https://calendly.com/vantekoandassociates/30min` with both popup and embedded on-page scheduler.
- **Ultra-Lightweight & Fast**: Single page, zero heavy frameworks, instant mobile responsiveness.

---

## 📅 How to Connect Your Own Calendly Link

Open `index.html` and search for:
```html
href="https://calendly.com"
```
Replace it with your personalized Calendly link (e.g. `https://calendly.com/your-username/consultation`).
